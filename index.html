本地阅览说明

  1. 双击 start_docs.bat：一键构建 MkDocs 站点并打开本入口页；
  2. 如 site/ 尚不存在或内容过期，请先运行 start_docs.bat 或 mkdocs build；
  3. 手工预览：mkdocs serve 后浏览器访问 http://localhost:8000；
  4. readme.md 与 docs/*.md 为 Markdown 源文件，推荐用 VS Code / Typora / GitHub 渲染查看。
  5. site/ 为本地构建产物（已 gitignore），在 GitHub 网页上请直接使用上方 docs/ 链接。
